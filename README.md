# WAES Technical Assessment: Interactive Quote Calculator

## Overview
This project was built as a technical demonstration for the WAES Full-Stack Development Bootcamp admissions review. It is a front-end web application designed to calculate custom printing quotes dynamically.

## Technologies Used
* **HTML5:** Semantic page structure and navigation.
* **CSS3:** Custom styling, interactive hover states, and background-image masking (`object-fit`/`object-position`).
* **JavaScript:** DOM manipulation, event listeners, and `if/else` conditional logic for dynamic price calculation.

## Project Features
* Multi-page navigation (`index.html`, `services.html`, `calculator.html`).
* Dynamic user input retrieval.
* Hidden UI elements revealed via JavaScript `onclick` events.
* Custom promotional code logic applying percentage-based discounts to the final injected total.
